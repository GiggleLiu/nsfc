\subsection*{依托平台}

本项目依托香港科技大学（广州）功能枢纽先进材料学域开展研究。香港科技大学（广州）是粤港澳大湾区重点建设的研究型大学，采用创新的枢纽-学域交叉学科架构，为前沿交叉研究提供制度保障。

申请人所在的功能枢纽汇聚了材料科学、物理学、计算科学等多学科人才，特别适合开展量子计算与形式化方法的交叉研究。枢纽内设有专门的量子技术研究中心，总面积超过1000平方米，其中洁净室面积600余平方米，可支撑大型量子实验平台的建设与运行。申请人团队正在该中心筹建基于铷原子的大规模里德堡原子阵列实验平台，预期将为本项目的算法验证提供实验支撑。

\subsection*{计算资源}

香港科技大学（广州）建有HPC AI融合智算中心，可为本项目提供充足的计算资源：

\begin{itemize}[leftmargin=2em, topsep=0pt, itemsep=2pt]
\item \textbf{通用HPC AI平台}：6.35 PFlops@FP64双精度浮点算力
\item \textbf{CPU资源}：Intel CPU 14656核 + AMD CPU 2560核
\item \textbf{GPU资源}：NVIDIA A800 GPU 520张 + A40 GPU 120张
\item \textbf{内存资源}：总内存容量2.3PB
\item \textbf{存储资源}：高速SSD 309TB + 大容量HDD 3.9PB
\item \textbf{国产AI平台}：19.04 PFlops@FP16半精度算力
\end{itemize}

该计算平台可充分满足本项目大规模张量网络计算、LLM微调训练、形式化证明搜索等计算密集型任务的需求。特别是A800 GPU集群可支持大语言模型的本地部署与微调，确保研究数据的安全性与计算效率。

\subsection*{国际合作网络}

申请人与国际顶尖研究团队建立了稳定的合作关系，可为本项目提供实验验证与理论支撑：

\begin{itemize}[leftmargin=2em, topsep=0pt, itemsep=2pt]
\item \textbf{哈佛大学Mikhail Lukin教授团队}：申请人在该团队完成博士后训练，双方保持密切合作。Lukin团队是国际里德堡原子量子计算领域的领军团队，拥有数百量子比特规模的实验平台。本项目开发的算法映射方案可在该平台进行验证实验。

\item \textbf{杜克大学Ruichao Ma教授团队}：Ma教授在超导量子系统与光场耦合方面具有丰富经验。本项目的通用归约框架不仅适用于里德堡原子系统，也可扩展到超导量子比特平台，双方将探索跨平台量子优化算法的验证与应用。

\item \textbf{国内合作网络}：申请人与清华大学、中国科学院物理研究所、港科大物理系、深圳国际量子研究院等机构保持合作关系，可获得理论研究与量子模拟的支持。
\end{itemize}

\subsection*{尚缺条件与解决途径}

\begin{itemize}[leftmargin=2em, topsep=0pt, itemsep=2pt]
\item \textbf{本地里德堡原子阵列实验平台（S4）}：申请人团队正在筹建基于铷原子的实验平台，预计项目中期完成搭建。过渡期内可依托国际合作获取实验验证时间。
\item \textbf{大规模LLM调用资源（S2）}：LLM驱动的规约合成需要大量模型推理调用。\textit{解决途径}：优先使用商用API接口进行推理；若需本地化部署，可利用校内A800 GPU集群。
\item \textbf{量子优化平台实验时间（S4）}：量子硬件实验时间受平台可用性约束。\textit{解决途径}：通过学术合作申请实验额度，合理规划实验批次以提高利用效率；必要时以数值模拟先行验证。
\end{itemize}

综上，本项目具备完善的平台支撑、充足的计算资源和广泛的国际合作网络，针对尚缺条件已制定可行的解决途径，为项目的顺利实施提供有力保障。
