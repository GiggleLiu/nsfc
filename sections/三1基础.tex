\subsection*{申请人研究背景}

申请人刘金国博士毕业于南京大学物理系，师从王强华教授。随后在中国科学院物理研究所从事博士后研究（合作导师：王磊研究员），从事物理与人工智能交叉领域研究。2020-2022年在哈佛大学Mikhail Lukin教授团队从事博士后研究，期间担任QuEra Computing Inc.全职顾问6个月，深度参与里德堡原子量子计算的产业化进程。现任香港科技大学（广州）功能枢纽先进材料学域助理教授，指导研究团队（7名博士生+1名硕士生）开展下一代量子计算设备与算法研究。

申请人在可微编程、张量网络、量子计算等领域发表论文40余篇，Google Scholar引用2800余次，h-index 15。2022年获北京市科学技术奖自然科学二等奖（排名4/9），该奖项涉及申请人参与发展的热带张量网络技术。申请人在哈佛期间与QuEra Computing Inc.共同申请美国专利（No. 63/323,863），为该公司量子优化求解器核心产品提供技术支撑。

\subsection*{代表性研究成果}

申请人在量子优化、问题规约、开源软件等方面积累了系统性研究成果，为构建问题规约编译器奠定坚实基础。以下列出四项直接相关的代表性成果：

\textbf{成果一：里德堡原子量子优化实验验证}

申请人作为核心成员参与了里德堡原子量子优化的首次大规模实验验证\cite{Ebadi2022Science}。该工作使用289个量子比特的里德堡原子阵列求解最大独立集问题，展现了相对于经典算法的超线性加速证据。申请人负责\textbf{问题映射方案}开发——这正是本项目规约编译器的核心功能。该成果发表于\emph{Science}，被评价为量子优化领域的里程碑式工作。

\textbf{成果二：三角晶格编码与自动化规约发现}

申请人近期提出三角晶格编码方案\cite{Pan2025Triangular}，将问题映射的质量因子从$Q=\sqrt{2}$提升至$Q=\sqrt{3}$，能量分离从8提高到27。更重要的是，申请人\textbf{首次将小工具设计形式化为整数线性规划问题}，在$4^{12} \approx 1600$万的搜索空间中自动发现12顶点交叉小工具。该方法验证了\textbf{计算机辅助规约发现}的可行性，是本项目LLM驱动规约发现的直接前期探索。

\textbf{成果三：热带张量网络精确求解}

申请人提出热带张量网络方法\cite{Liu2021PRL}，将张量网络技术与热带代数结合，实现组合优化问题的精确求解。该方法可作为规约正确性验证的工具——通过精确求解小规模实例，验证规约的解保持性和解可提取性。该成果发表于\emph{Physical Review Letters}。

\textbf{成果四：量子计算开源软件生态}

申请人主导开发了多个有影响力的开源软件，为编译器构建提供技术基础：
\begin{itemize}
	\item \textbf{Yao.jl}：Julia生态最流行的量子模拟器，GitHub近千星标\cite{Luo2020Quantum}
	\item \textbf{GenericTensorNetworks.jl}：泛型张量网络库，为QuEra公司提供技术支撑\cite{Liu2023SIAM}
	\item \textbf{UnitDiskMapping.jl}：单位圆盘图映射库，实现里德堡编码方案
	\item \textbf{problem-reductions}：问题规约库（Rust语言），本项目将扩展至100+规约规则\cite{ProblemReductions2025}
\end{itemize}
这些软件构成编译器的技术基础设施，可直接复用和扩展。

\subsection*{可行性分析}

\textbf{1. 理论可行性}

规约代价模型的核心思想——将规约开销表示为问题规模的多项式——在计算复杂性理论中有坚实基础。渐进分析方法已被广泛用于算法比较，本项目将其扩展到多变量情形是自然的推广。路径优化问题在图算法领域有成熟的技术储备。

\textbf{2. 方法可行性}

申请人已在三角晶格编码工作中验证了ILP辅助规约发现的有效性。将LLM与ILP结合的思路受AlphaEvolve\cite{AlphaEvolve2025}启发，后者已在数学问题发现中展示了LLM+自动验证的强大能力。测试先行方法在软件工程中已被证明可提高代码质量，将其应用于规约发现是创新但可行的尝试。

\textbf{3. 系统可行性}

编译器架构基于申请人开发的problem-reductions库，该库已实现问题定义和规约规则的基本框架。路径规划器可基于标准图算法实现；后端代码生成器可复用UnitDiskMapping.jl和D-Wave Ocean SDK。核心技术模块均有可复用的基础。

\textbf{4. 实验可行性}

申请人与Harvard/MIT Lukin团队、QuEra Computing保持密切合作，可获得里德堡原子实验平台的访问权限。D-Wave Leap云服务提供商用级量子退火机访问。这些合作确保编译器生成的规约可在真实硬件上验证。

\textbf{5. 风险控制}

本项目设置了多层备选方案：
\begin{itemize}
	\item 若LLM生成效果不理想，可退回ILP精确搜索作为基准
	\item 若代价模型理论过于复杂，可先采用启发式路径选择
	\item 若100+规约目标过于激进，可优先覆盖最常用的问题类型
	\item 三角晶格编码已有成熟实现，可作为编译器的首个验证目标
\end{itemize}
这种渐进式策略确保项目在不同技术路线上均有产出。
